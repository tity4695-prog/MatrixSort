# Сортировка чётных строк матрицы

## О программе

Данная программа работает с вещественной матрицей. Она сортирует элементы
чётных строк матрицы по возрастанию.

Программа была разработана в рамках лабораторной работы по дисциплине
«Инструментальные средства разработки программного обеспечения».

## Требования

Для запуска программы нужен Python 3.x.
Программа может работать в Windows или Linux.

Используется стандартная библиотека random.

## Как работает программа

Сначала программа запрашивает количество строк и столбцов матрицы.
После этого создаётся матрица со случайными вещественными числами.

Затем программа выводит исходную матрицу и сортирует элементы 2-й, 4-й,
6-й и других чётных строк по возрастанию методом пузырька.

После сортировки на экран выводится получившаяся матрица.

## Запуск

Для запуска программы нужно открыть папку src и выполнить команду:

python main.py
